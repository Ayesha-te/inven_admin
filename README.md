# Admin Panel

Standalone React app for admin approval and user management.

## Run

```bash
npm install
npm run dev
```

Default local URL: `http://localhost:5174`

## Environment

- `VITE_API_BASE_URL` points to the backend base URL.

Example:

```bash
VITE_API_BASE_URL=https://clumsy-virgie-aamzaabdul-f5d0773e.koyeb.app
```
